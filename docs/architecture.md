# ServiceAgent 架构说明

© 2026 上海如静知华信息科技有限公司

## 设计目标

面向客服中心、服务主管和客户成功团队的客户服务 Agent 社区源码项目。系统提供工单分流、知识政策检索、回复草拟、情绪风险识别、隐私遮蔽和人工接管流程。

Vue H5 / Web → Spring Security → Controller → Domain Service → JPA / MySQL

AgentRuntime 是模型与工具执行边界。社区版默认使用确定性的本地演示执行器，业务策略由普通 Java 服务实现并可单元测试。接入真实模型、知识库、MCP 工具或企业系统时，应通过适配器完成，不要把密钥、提示词权限或外部调用散落在控制器中。

## 安全边界

- JWT 与角色区分管理端、业务端和评测角色。
- Agent 建议保留输入事实、证据和人工修订记录。
- 高影响动作必须通过领域服务的人工审批门禁。
- 外部工具使用最小权限、超时、幂等和审计策略。
- 客户资料库密码、模型密钥和第三方令牌只从环境变量读取。

CustomerResponseGuardService 对隐私数据、退款赔付和高情绪风险进行分级；高风险回复必须经主管复核或转由人工坐席处理。
